## 1. Título del ejercicio

**Ejercicio 1 — Sensor de movimiento PIR con LED**

## 2. Descripción breve del circuito y su funcionamiento

En este ejercicio se utiliza un sensor de movimiento PIR conectado a una entrada digital del Arduino.
El sensor detecta si existe movimiento y envía una señal digital al Arduino mediante el pin 2.
Cuando se detecta movimiento, el Arduino enciende el LED incorporado y muestra en el monitor serial el mensaje de activación.
Cuando no se detecta movimiento, el LED permanece apagado.

## 3. Componentes utilizados

* 1 placa Arduino Uno
* 1 sensor de movimiento PIR
* 1 LED incorporado de la placa Arduino
* Cables de conexión
* Computadora para programar y simular el circuito en Tinkercad

## 4. Instrucciones de uso

1. Ingresar a Tinkercad y abrir la sección **Circuits**.
2. Abrir el proyecto del sensor PIR mediante el enlace público del proyecto.
3. Si se desea replicar el circuito, colocar una placa Arduino Uno y un sensor PIR.
4. Conectar la salida digital del sensor PIR al pin digital 2 del Arduino.
5. Iniciar la simulación.
6. Al detectar movimiento, el LED del Arduino debe encenderse.
7. Revisar el monitor serial para observar el mensaje **"Sensor activated!"**.
