## 1. Título del ejercicio

**Ejercicio 3 — Sensor de temperatura con tres LEDs**

## 2. Descripción breve del circuito y su funcionamiento

En este ejercicio se utiliza un sensor de temperatura conectado a la entrada analógica A0 del Arduino.
El Arduino realiza una lectura de la temperatura y la convierte a grados Celsius y Fahrenheit para mostrarla en el monitor serial.
Dependiendo del nivel de temperatura detectado, se encienden diferentes LEDs conectados a los pines digitales 2, 3 y 4.
De esta manera, los LEDs indican visualmente los diferentes niveles de temperatura detectados por el sensor.

## 3. Componentes utilizados

* 1 placa Arduino Uno
* 1 sensor de temperatura
* 3 LEDs
* Cables de conexión
* Computadora para programar y simular el circuito en Tinkercad

## 4. Instrucciones de uso

1. Ingresar a Tinkercad y entrar en la sección **Circuits**.
2. Abrir el proyecto mediante el enlace público de Tinkercad.
3. Para replicar el circuito, colocar una placa Arduino Uno, un sensor de temperatura y tres LEDs.
4. Conectar el sensor de temperatura a la entrada analógica A0.
5. Conectar los LEDs a los pines digitales 2, 3 y 4.
6. Iniciar la simulación.
7. Modificar la temperatura del sensor y observar cómo se encienden los LEDs según el nivel de temperatura.
8. Abrir el monitor serial para observar los valores de temperatura en grados Celsius y Fahrenheit.
